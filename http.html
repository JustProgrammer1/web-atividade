Protocolo HTTP

O HTTP (HyperText Transfer Protocol) é o protocolo utilizado para comunicação entre cliente e servidor. Quando um cliente faz uma solicitação, o servidor devolve uma resposta normalmente no formato HTML.

Funcionamento

O cliente envia uma requisição (request) ao servidor. O servidor processa essa requisição e retorna uma resposta (response).

Request

A requisição é enviada pelo cliente e pode utilizar métodos como GET ou POST. Os dados enviados são organizados pelo atributo name.

Response

A resposta é enviada pelo servidor e normalmente contém uma página HTML.
