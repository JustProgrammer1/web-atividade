Protocolo HTTP

O HTTP (HyperText Transfer Protocol) é o protocolo responsável pela comunicação entre navegadores (clientes) e servidores na Web. Ele permite a troca de informações como páginas HTML, imagens e outros recursos.

Como o HTTP funciona

Quando você acessa um site, seu navegador envia uma requisição HTTP ao servidor, que responde com os dados solicitados.

Passos:

  • Cliente faz requisição
  • Servidor processa
  • Servidor envia resposta
  • Cliente exibe o conteúdo

Exemplo de Requisição HTTP (Request)

GET /index.html HTTP/1.1
Host: www.exemplo.com
User-Agent: Mozilla/5.0
Accept: text/html

Explicação dos campos:

  • GET: método da requisição
  • /index.html: recurso solicitado
  • HTTP/1.1: versão do protocolo
  • Host: servidor de destino
  • User-Agent: navegador do usuário
  • Accept: tipo de conteúdo aceito

Exemplo de Resposta HTTP (Response)

HTTP/1.1 200 OK
Content-Type: text/html
Content-Length: 1024


  
    
Olá Mundo!

Explicação dos campos:

  • 200 OK: status da resposta
  • Content-Type: tipo do conteúdo
  • Content-Length: tamanho da resposta
  • Body: conteúdo retornado

Exemplo prático

Ao acessar um site, o navegador envia uma requisição GET e recebe um HTML como resposta.
