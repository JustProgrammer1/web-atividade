Internet x Web

A Internet é a rede mundial de computadores interligados que permite a comunicação entre dispositivos. A Web (World Wide Web) é um sistema que funciona sobre a internet, permitindo acessar páginas por meio de navegadores. A Web utiliza HTML para estruturar páginas e HTTP para comunicação entre cliente e servidor.

História da Web

Nos anos 90 surgiu o HTML, criado por Tim Berners-Lee no CERN, com o objetivo de facilitar a troca de informações. As páginas HTML são armazenadas em servidores e acessadas por clientes (navegadores) utilizando o protocolo HTTP.

Em 1994 foi criada a W3C, responsável por desenvolver padrões e diretrizes para o crescimento da web.
