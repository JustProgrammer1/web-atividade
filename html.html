Diferença entre Internet e Web

A Internet é uma rede mundial de computadores conectados entre si. Já a Web é um sistema que permite acessar páginas por navegadores. Ou seja, a Internet é a infraestrutura e a Web é um serviço dentro dela.

História da Internet e da Web

A Internet surgiu como ARPANET nos anos 1960, inicialmente para uso militar.

Nos anos 1980, o protocolo TCP/IP permitiu a expansão da rede. Já a Web foi criada por Tim Berners-Lee em 1989.

Principais marcos

  • 1983 - TCP/IP
  • 1989 - Web
